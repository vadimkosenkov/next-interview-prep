# ⚡ PrepFlow — Interview Preparation

A Next.js application for practicing frontend & backend technical interview questions. Browse topics grouped into blocks (HTML/CSS, JavaScript, TypeScript, Angular, React, Next.js, NestJS, Node.js, SQL, Git), take quizzes with instant feedback, and track your progress over time — all persisted locally in the browser.

🔗 Repository: https://github.com/vadimkosenkov/next-interview-prep

## 🚀 Key Features

- Question blocks covering HTML/CSS, JavaScript, TypeScript, Angular, React, Next.js, NestJS, Node.js, SQL, and Git, each split into topics.
- Quiz mode per topic or across an entire block, with shuffled question order.
- Instant answer feedback with explanations and an optional "Read theory" deep dive per question.
- Per-topic and aggregate progress tracking (answered/correct counts, accuracy).
- Dashboard with overall statistics, progress by topic, and session history.
- RU/EN localization for the app UI.
- Light/dark theme toggle.
- Persistent progress, history, and language preference via Local Storage — no backend required.
- Fully responsive layout for desktop, tablet, and mobile devices.

## ⚙️ Quick Start

### 1. Clone the repository

```bash
git clone https://github.com/vadimkosenkov/next-interview-prep.git
cd next-interview-prep
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
